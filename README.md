# AI Career Copilot – Resume Analyzer 🚀

## 📌 Project Description
AI Career Copilot is an AI-powered Resume Analyzer designed to help students and job seekers improve their resumes and prepare for internships and job opportunities.

It analyzes a candidate's resume based on a given job description and provides useful feedback to improve their chances of getting selected.

## ✨ Features
- Resume Analysis
- Job Description Matching
- Resume Score
- Skill Gap Identification
- Suggestions for Resume Improvement
- AI-Powered Feedback

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Google Gemini API

## ⚙️ How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter your resume details.
5. Paste the job description.
6. Click the Analyze button.
7. View your AI-generated resume analysis.
